# Mininotes

Mininotes 是一本用在手机和电脑上的笔记本：它让你的笔记、文件夹和文件在你所有设备上保持一致，并与你选择的人共享。没有服务器，不需要账号，中间也没有任何人：一切都经端到端加密，通过 Minima 网络传送，或者在同一 Wi-Fi 下直接从一台设备传到另一台。

[![最新版本](https://img.shields.io/github/v/release/mininotesorg/mininotes?label=latest%20build)](https://github.com/mininotesorg/mininotes/releases/latest)

## 1. 最新变化

最新的在前。除非另有说明，每个版本在手机和电脑上都一样。

### 0.4.028

- 你分享的已盖时间戳的笔记或文件会带着它的时间戳：与你分享的人可以在 *在 Minima 上盖时间戳…* 中看到它；只有当收到的内容完全相同时，才会显示为所收到内容的时间戳，并附有在 Minima Explorer 上核验的链接。分享之后再盖的时间戳也会传给对方。
- 分享一个 Integritas 报告放在旁边的文件时，*同时发送 Integritas 报告* 会把报告一并发送。

### 0.4.024 至 0.4.027

- **在 Minima 上盖时间戳…** 现在是笔记或文件菜单中的一行，显示它的时间戳进行到哪一步，并打开一个包含一切的窗口：盖时间戳、在 Minima 上查找、再次核验、以前盖过时间戳的版本，以及把文件与指纹比对。Integritas 的 PDF 报告可以附加到笔记中，或放在文件旁边。
- 时间戳会传到你的其他设备：在手机上盖过时间戳的内容会列在电脑上，反过来也一样。
- 盖过时间戳的文件，图标上会有一个小印章。
- *与指纹比对…*：粘贴别人给你的某个文件的 SHA-256，立刻就能看出是不是同一个文件。没有任何东西离开设备，也不需要账号。
- Integritas 的回答会用你的语言显示；它没有立即回答时，会再问一次。
- 在电脑上，每个界面、按钮和指针下的说明文字都是你的语言；新笔记本的第一批文件夹也用这种语言命名。在法语中，新笔记会标上 *nouv.*
- 手机还在连接中继时，如果屏幕重绘，它不会再停止响应。

## 2. 安装

**Android**（9 或更高版本）：从[最新发布版](https://github.com/mininotesorg/mininotes/releases/latest)下载 `Mininotes-<version>.apk`，确认它就是发布的那个文件，然后在手机上打开：

```sh
sha256sum -c Mininotes-<version>.apk.sha256
```

Android 会询问是否允许从你下载它的地方安装应用；之后可以再关闭这项权限。

**查看签名者**。每个发布版 APK 都用同一个 Mininotes 密钥签名。它的 SHA-256 证书指纹，按 [AppVerifier](https://github.com/soupslurpr/AppVerifier) 接受的格式如下（复制这两行，然后选*Verify from clipboard*）：

```
org.mininotes.android
F7:91:C2:14:D9:ED:9B:E9:DE:EC:6F:15:BE:D0:25:38:35:22:DD:F9:A8:21:23:4A:73:90:C8:1B:60:1F:91:AB
```

或者用 Android SDK：`apksigner verify --print-certs Mininotes-<version>.apk`。任何其他指纹，都不是来自本仓库发布版的构建。

**Windows**（10 或 11）：从同一个发布版下载 `Mininotes-Windows-<version>.msi` 并打开它。它不需要管理员权限，安装后 Mininotes 会像其他应用一样出现在 Windows 的“设置”、“应用”中。在那里卸载会保留你的笔记，以后再次安装时会重新找到它们；应用菜单中的 *卸载 Mininotes…* 也可以删除笔记，但会先建议备份。其中已包含 Java，无需另外安装任何东西。

或者，如果你更喜欢，也可以用 `Mininotes-Windows-<version>.zip`：解压到任意位置，然后打开 `Mininotes.exe`。

两者都不需要别的东西：传送你笔记的 Maxima 节点就在应用里面。

## 3. 书写

- **横线纸，随时可写**。笔记打开时光标已经在里面，边写边保存。没有保存按钮。
- **标签页**。一条笔记可以有多页，就像索引卡一样：*添加标签页*。拖动标签页即可调整顺序。
- **粗体、斜体和下划线**。在文字两边输入标记，`**bold**`、`*italic*` 和 `__underline__`，或者在键盘上按 Ctrl+B、Ctrl+I 或 Ctrl+U。
- **两人同写一条笔记**。如果两个人在看到对方内容之前都在同一条笔记里写了东西，两份内容会逐行合并，谁写的都不会丢失。每个人写的内容可以用各自的颜色显示：点按标题下方的圆形头像即可更改。
- **来自其他应用**。在 Android 上，Mininotes 出现在分享菜单中：截图、照片、文件、文字或链接可以放进一条新笔记，或放进你最近用过的笔记。

## 4. 整理：主页、文件夹、程序坞和收藏

- **主页**以图标的形式放着你的笔记和文件夹，页数随你，每样东西都在你放的位置。
- **新建内容**。点按 + 可以新建笔记或文件夹，或者从这台设备或另一台设备添加文件。
- **它的菜单**。长按图标打开它的菜单：颜色、图标、移动、共享等等。在电脑上则右键单击；在电脑上，点标志会回到主页，还可以拖动分隔线来调整侧边列表的宽度或把它收起。
- **文件夹**可以放笔记和其他文件夹，层级不限。把任何东西拖到文件夹上，就能放进去。
- **移动**。长按并拖动图标：放进文件夹、从文件夹中拿出，或移到另一页。拖动时，顶部的横条让你直接把它放到某个收藏、Temp、归档、回收站或共享上，不用打开菜单。
- **页面**。在页面之间滑动切换。在主页上双指捏合，或在菜单中选择*所有页面*，可以一次看到所有页面。
- **颜色和图标**。每条笔记和每个文件夹都可以从菜单中设置自己的颜色，以及自己的图标或图片。颜色的深浅也各自独立，用颜色下方的滑块调节。主页的颜色会成为整个应用的颜色。
- **程序坞**是主页底部的那一排：放在那里的东西，一点即达。除收藏外，每条笔记和每个文件夹的菜单中都有*添加到程序坞*。它能放的数量不限，放不下时可以横向滚动。每台设备都有自己的程序坞，它从不会发送到你的其他设备。
- **收藏**把你常回来看的东西集中在一处。新加的收藏也会放进程序坞；取消收藏后，它仍留在程序坞中。
- **最近**列出你最近打开过的内容：在电脑上位于侧边，在手机上位于主页。*从最近中移除*（在电脑上右键单击）会把某项从列表中拿掉，不会删除任何东西。在手机上，从程序坞向上滑，或点按它上方的小把手，就能以卡片形式翻看最近的内容：点按卡片打开，把它滑走或按返回键关闭。
- **Temp** 用来放只需要用一阵子的东西，也用来在你自己的设备之间、以及与你选择的人之间传递东西：里面的内容会发给他们，时间一到，就会在所有地方消失。
- **与我共享**放着别人与你共享、等待你回复的内容（参见[与他人共享](#6-与他人共享)）。
- 主页底部的**搜索**按文字查找笔记、文件夹和文件。**目录树**一次显示所有内容。
- **归档和回收站**：一个是收起来，一个是准备丢掉。两处的东西都可以放回（参见[版本、归档、回收站和备份](#11-版本归档回收站和备份)）。
- 主页上的 **README** 就是这份文字，和 GitHub 上的一样，只是去掉了只在那里才有意义的部分（目录、最新变化、安装、构建，以及每个菜单项的列表，这些说明电脑会在指针下显示）。
- *设置*中的**在主页显示**决定主页显示哪些位置（最近、Temp、与我共享、归档、回收站），以及是否显示 README。关闭的位置仍在菜单中。
- **照片**：主页上默认有一个相册文件夹，其中每张图片以网格排列，每张都可以放大打开，滑动一下或点一下箭头，就能看下一张或上一张。用它的 + 添加照片，或者拍一张。任何文件夹都可以从菜单中设为相册显示。

## 5. 你自己的设备

把手机和电脑关联一次（*联系人和设备*，然后*添加我的设备*，用其中一台扫描另一台上的码）。从那以后，你与自己的设备共享的内容，会在你停止书写几秒后，在所有设备上双向自动保持最新。如果你的某台设备只需要查看，可以把它设为*可阅读*。每台设备都保留自己的布局：你在一台设备上把笔记放在哪里，不会改变它在另一台上的位置，而且每台设备都有自己的程序坞。

## 6. 与他人共享

- **添加某人**：扫描对方的码，或打开对方发给你的链接；对方也用你的码或链接做同样的事。
- **共享笔记、文件夹或文件**：在它的菜单中选择*同步和共享*，然后选*共享…*。先选择对方可以做什么，再选一个人或一个群组，或者向对方出示你的码。每个人都有一个角色：*所有者*（创建者）、*管理员*、*可编辑*或*可阅读*，随时可以在其旁边的下拉菜单中更改，或者将其移除。
- 任何 + 中的**来自另一台设备…**，用来接收别人向你出示的内容。
- **群组**，比如朋友或同事，把人归在一起：与群组共享时，其中每个人都获得相同的角色，包括之后加入的人。
- **接受或拒绝**。有人与你共享时，会有一条消息告诉你，内容会在*与我共享*中等待。你能看到它是什么、是谁发来的，并在它出现在任何其他地方之前，选择把它放到哪里。选*接受*保留它，或者选*拒绝*，可以默默拒绝，也可以回复对方一句话。
- **颜色随行**。你给共享笔记设置的颜色会跟着它走，每台设备可以设置自己的深浅。
- **共享文件夹里的一切都会共享**。你放进已共享文件夹的任何东西，都会发给你与之共享该文件夹的人。
- 笔记标题旁的**圆形头像**代表拥有这条笔记的人和设备，各自显示其图片或首字母。点按一个，即可放大显示其图片。在电脑上，把指针停在圆形头像上，会显示那是谁、他们可以对这条笔记做什么、他们的内容同步到了哪一步，以及还有多少个文件正在发给他们。

## 7. 联系人和设备，以及我的个人资料

两者都在菜单中*同步和共享*的末尾。

- **联系人和设备**列出你添加的人、你自己的设备和你的群组，各占一页。某个人的页面会显示你与其共享的内容，还能让你给对方设置一张你自选的图片，只有你看得到。群组的设置在它的 › 后面。
- **联系人旁的 +** 用来与某人建立联系：扫描对方的码、粘贴对方的链接，或者用*分享我的链接*通过消息或聊天发送你的链接。**我的设备旁的 +** 用来添加你自己的另一台设备。
- **我的个人资料**存放属于你的东西：
  - 你的**名字**和你的**图片**，会发给与你配对的人；
  - 你的 **Parlons! 地址**，会自动发给你的联系人；
  - 你的码和你的链接，供别人添加你；
  - **Integritas** API 密钥（参见[用 Integritas 在 Minima 上盖时间戳](#13-用-integritas-在-minima-上盖时间戳)）；
  - 在电脑上，**文字大小**：由 A− 和 A+ 组成的五级阶梯，从“较小”到“最大”，作用于整个应用（主页、最近、菜单、对话框），下次启动时生效，并附有*立即重新启动*；
  - 在电脑上，**说明每一项的作用**，默认开启，用来开启或关闭指针停在菜单项或圆形头像上时显示的简短说明；
  - *管理…*，用来打开联系人和设备。

## 8. 随时了解每样东西的状态

- 每条笔记、每个文件夹和每个图标上的**标记**表明它的状态：空心灰色圆环表示只在这台设备上；琥珀色箭头表示正在等待发送（按一下即可立即发送，并查看仍在等待的每条笔记和每个文件）；三个琥珀色圆点表示已发送、正在等待回复；绿色对勾表示每个人都有这个版本；两条灰色竖条表示已暂停；红色感叹号表示有一台设备已经超过三天没有联系上。
- **新**列出自你上次查看以来的变化：别人写过的笔记、与你共享的东西、收到的文件，以及每一项是谁发来的、何时发来、放在哪里。
- **顶部的横条**会在某个联系人出了问题时出现（设备好几天都没联系上、处于锁定状态，或者装的是较旧的 Mininotes）。Mininotes 会自己不断重试，*怎么办*会告诉你可以做什么。

## 9. 文件、照片和录音

- **附加**：把任何文件附加到笔记或文件夹，可以一次附加多个。
- **拍照**：从笔记中拍照，使用手机的相机，或者在电脑上使用 Windows 自带的相机，拍下的照片直接进入笔记。
- **录音**：在笔记中录制音频。
- **轻装传送**。照片在添加时会缩小，所以一条有五十张照片的笔记，传送起来依然很轻；可以在*设置*、*图片和文件*中关闭这项功能。其他文件会被压缩，以节省空间。
- **预览**。PDF 的卡片显示其第一页；Word、PowerPoint、Excel、OpenDocument、RTF、HTML 或文本文件的卡片显示其开头几行。预览由 Mininotes 根据文件本身绘制，从不交给 Windows 或其他应用，因此不会在外部留下它们的任何图片。
- **打开**：用电脑为这类文件设定的程序打开它（例如*用 LibreOffice 打开*），或者用*打开方式…* 选择其他程序。你保存的更改会回到 Mininotes，并发送到你的设备。
- 文件上的**复制**（在电脑上右键单击，在手机上长按）会把文件本身放到剪贴板，图片则作为图片，可以直接粘贴到其他应用中，无需先保存。
- **保存到外部**。*保存到我的电脑…*（手机上是*保存到我的手机…*）会把一份副本保存到你选择的位置。*保存到我的设备…* 还会把它作为文件保存在这台设备的一个文件夹里。
- 手机上的**用其他应用发送…** 会打开手机自带的分享功能，例如通过 WhatsApp 发送文件。长按文件后选择*选择多个…*，可以勾选多个文件，一起这样发送或移到回收站。
- **在电脑上一次处理多个**。回形针菜单中有*附加文件*、*拍照*和*录音*，下面是笔记中的文件，每个都有一个可勾选的框：*全选*，然后对勾选的文件选择*保存到我的电脑…*（多个文件会放进同一个文件夹）、*在 Minima 上盖时间戳…* 或*移到回收站*。
- **发送文件**：直接发送到你的另一台设备或你添加的某个人，不放进任何笔记，在同一 Wi-Fi 下点对点传送。收到的东西会出现在主页上，在你打开之前都标为*新*。
- **在 Minima 上盖时间戳…**（在文件或笔记的菜单中）：参见[用 Integritas 在 Minima 上盖时间戳](#13-用-integritas-在-minima-上盖时间戳)。

## 10. 留在电脑上的文件

- **通过 Mininotes 共享文件**（在电脑上的*同步和共享*中）：电子表格或文档留在电脑上原来的位置，并用它自己的程序打开。每次你保存它，那个版本就会发送到你的其他设备，而在别处保存的版本也会写回这个文件。传送的是整个文件的最新版本：电子表格内部的更改不会合并。如果它在两处都改过，而两边还没同步，Mininotes 会询问保留哪个版本，在你回答之前不会替换任何东西。
- **同步这台电脑上的文件夹**（在电脑上的*同步和共享*中）：选一个文件夹，在 C: 盘或任何位置都行，其中的所有内容都会在 Mininotes 中显示为一个文件夹，并标明它位于你的电脑上。你放进去的文件，无论是在资源管理器中还是从任何程序放入，都会在几秒后被收入，并发送到你的设备以及你与之共享该文件夹的人；从他们那里来的文件会写入这个文件夹。文件留在你电脑上的这个文件夹里，在应用之外。在磁盘上删除一个文件，绝不会在 Mininotes 中删除它，反过来也一样；如果一个文件在两处都改过，Mininotes 会询问保留哪个版本。在手机上，这个文件夹里的文件保存在应用内。
- **笔记作为文件**。笔记或文件夹也可以作为 Markdown 文件，保存在电脑上你选择的文件夹里（*保存到我的设备…*）。Mininotes 从不删除这些文件，私密笔记也从不会被写出。
- 这样的文件夹，其图块上会显示一个带箭头的文件夹。它的菜单会显示它在电脑上的位置，然后是*在资源管理器中显示*、*仅保存在应用内*和*从应用中移除*。

## 11. 版本、归档、回收站和备份

- **版本**。笔记的每个版本都会保留；*版本…* 可以恢复其中任意一个。
- **归档**把东西收起来，不再显示；**回收站**保存你删除的内容，包括文件，直到你清空它。两者都在主页上，也都有返回的路。*放回*会把东西放回原来的位置。
- **回收站里的笔记文件**。从笔记中移除的文件会立即进入回收站，不会询问，并在你所有设备上、对这条笔记发送到的每个人，都从笔记中移除。*放回*会让它在所有地方回来。只有清空回收站后，它才会永久消失。
- **备份**。*导出备份*会写出一个包含所有文件夹、笔记和文件的文件。如果没有开启锁定（参见[隐私、加密和安全保障](#14-隐私加密和安全保障)），它会要求你为这份备份设置密码。*从备份添加*会恢复一份备份，并询问是添加到现有内容中，还是替换现有内容。

## 12. 助手：提出要求，交给它去做

**助手**（在电脑上位于顶栏，在手机上位于菜单旁边，或按 Ctrl+K）根据应用内附带的帮助（[英文帮助](android/app/src/main/resources/org/mininotes/android/help/en.txt)、[法文帮助](android/app/src/main/resources/org/mininotes/android/help/fr.txt)）回答关于 Mininotes 的问题，并完成用英语或法语说出的简单任务：*what is new?*、*what is on my todo list?*、*add milk to Grocery*、*share Grocery with Carol*、*add a contact*、*open*、*find*、*new note called…*、*put … in the dock*。它在你的设备上运行，不用模型，也不用服务器，不发送任何东西；任何会传到别人那里或会改动笔记的操作，它都会先给你看再执行，并会主动带你去正确的位置。在它的框外点一下，即可关闭。

## 13. 用 Integritas 在 Minima 上盖时间戳

有了 [Integritas](https://docs.integritas.technology/) 账户，就可以从文件或笔记的菜单中，为它在 Minima 区块链上盖时间戳。离开设备的只有它的指纹（SHA-256），文件本身从不离开。

- **在 Minima 上盖时间戳…** 会记录下文件此刻的确切样子：这是一份证明，表明从那一刻起它就存在，而且之后没有改动过。它会用掉你 Integritas 账户的一次时间戳。
- **在 Minima 上核验…** 会在之后把文件与记录的内容进行核对：它是否盖过时间戳、是否未被改动，以及记录在哪个区块、哪一天。它不改变任何东西，也不花任何费用。
- **区别**：盖时间戳是一次性写下证明；核验是把它读回来，次数不限。
- **笔记的时间戳**涵盖它的标题、一个空行，然后是正文；重命名会让它显示为已更改。0.4.018 之前盖的时间戳只涵盖正文：*笔记，仅正文*。
- **我的个人资料，时间戳**：粘贴你的 API 密钥并按*保存*；它保存在你的笔记本中，随笔记本一起锁定，从不放进备份。在*也在我的设备上*下开启你自己的任意设备，密钥也会发给它们，并为每台设备单独加密。
- **已在 Minima 上盖时间戳…** 位于*查找*的最后，列出在这里盖过时间戳的内容；打开一项，可以查看其指纹、区块和交易。它的 **+** 可以为 Mininotes 中的笔记或文件盖时间戳，也可以为这台设备上未放入 Mininotes 的文件盖时间戳。

## 14. 隐私、加密和安全保障

- **没有服务器，没有账号，没有跟踪**。笔记保存在你的设备上，只会发给你与之共享的人和设备。
- **端到端加密**。每条笔记和每个文件，都会为它要去的设备单独加密，然后由 [Maxima](https://minima.global) 中继传送，中继只转发它们无法读取的消息；或者在同一网络下，直接从一台设备传到另一台。
- **锁定 Mininotes**（*设置*、*安全*）会加密设备上的笔记本、其中的文件以及你的备份。在手机上用指纹或屏幕锁打开，在电脑上用 Windows Hello 或你的密码打开，另有 12 个恢复词作为备用钥匙：请把它们写下来。不开启它，笔记在设备上就不加密。
- **有两样东西会使用网络**：传送你所共享内容的 Maxima 节点，以及每天一次到这个仓库查看是否有新版本，这一项你可以关闭。[docs/SHARING.md](docs/SHARING.md) 说明了哪些内容经过加密、哪些经过签名，以及哪些还没有实现。

## 15. 私密空间和求助

**私密空间**

- **打开或新建一个**。在任意笔记中，输入单词 private，然后输入 //: 和你的密码，全部连在一起，中间不留任何东西，再按回车。输入冒号的那一刻，代码就会从笔记中消失，密码则输入到单独的框中，所以两者都不会留在笔记里。这个密码打开的空间，会显示在单独的屏幕上，覆盖整个窗口。如果是从未用过的密码，再输入一次，就会创建一个新的空空间。
- **一个密码对应一个空间**。每个不同的密码都是一个独立的空间。你可以创建的数量没有上限，任何地方也都不会记录你有多少个。
- **把每个密码都写下来**。因为没有任何地方记录它们，输错的密码会被当作新空间，要求你再输入一次：如果你本想打开已有的空间时发生这种情况，请关闭对话框再试一次。新空间可能会覆盖在较早的空间上，使其丢失一部分内容。
- **你在哪里**。私密屏幕有自己的颜色，*私密*旁边还有一把锁，所以你总能知道自己在哪里。用底部的 + 新建笔记、文件夹和文件。按住密码旁边的眼睛图标，可以显示密码。按返回键会关闭这个空间。
- **删除一个空间**。打开它，在它的菜单中选择*删除这个私密空间*。它会被永久删除，之后它的密码什么也打不开。
- **使用长密码**。用由几个词组成的长短语作为密码。忘记的密码谁也无法找回，即使有 12 个恢复词也不行。
- **它能容纳什么**。一个空间总共约能容纳 64 MB，足够存放笔记和大约五十张照片。其中的笔记、文件夹、照片和文件不会在其他任何地方显示，目前只保存在这台设备上，不能共享或发送，并且会在你离开 Mininotes 或五分钟未使用后关闭。
- **代码从不会保留在普通笔记中**。如果有代码留在笔记里，Mininotes 会在保存、发送或共享这条笔记之前，把它连同所在行的其余内容一起删掉。
- **文件**。+ 中的*来自这台设备…* 会把文件添加到空间里，并在其中加密保存。除非你选择删除，原文件会留在原处，而且手机的文件选择器会保留它自己的最近打开文件列表。
- **小提示**。你可以用一个密码保存一个看起来可信的空间，用另一个密码保存真正的空间，并时不时用一下那个可信的空间，让它看起来像是常用的。
- **它们的局限**。私密空间的设计，是让任何读取应用文件或代码的人都看不到它们，也无法得知有多少个。但这无法确认是 100% 安全的，所以只在里面存放即使被发现也不会伤害到你的东西。

**紧急联系人**

- **这是什么**。一旦打开某条私密笔记，求助就会把你的位置和你选择的话，发给你选择的人。它用于你可能身处危险、有人可能逼你打开 Mininotes 的情况。
- **设置求助**。打开一个私密空间，打开其中一条笔记，输入单词 help，然后输入 //:，全部连在一起，再按回车。代码会立即消失，并弹出一个对话框，询问要通知谁、说什么。你输入代码的那条笔记，就是会发出求助的那条。只有知道这个空间密码的人，才能设置或取消求助。
- **不再显示**。设置后，它在任何地方都不会再显示：没有任何菜单提到它，对话框每次打开都是空的。
- **全部取消**。要取消一个空间的所有求助，在其中一条笔记中输入单词 erase，然后输入 //:。这个代码也会立即消失。
- **位置**。为此，Mininotes 会请求手机的位置权限，系统会在使用位置时显示出来。

## 16. 语言和翻译

Mininotes 支持十一种语言：英语、法语、德语、西班牙语、意大利语、葡萄牙语、俄语、中文、日语、印地语和波斯语。首次启动时它会询问使用哪种语言，并已预先选好设备自身的语言，这份 README 也会使用该语言；*设置，语言*会同时更改两者。笔记菜单中的*翻译…* 会在设备上把这一页译成另一种语言，不会发送给任何翻译服务。

## 20. 自己构建

**Android** 需要 JDK 17 和 Android SDK（compileSdk 36）：

```sh
cd android
./gradlew testReleaseUnitTest lintRelease assembleRelease
```

APK 会生成在 `android/app/build/outputs/apk/release/` 中，未签名：用你自己的密钥签名，或者使用 `./gradlew installDebug`。`android/local.properties` 指向你的 SDK，不在仓库中。

**Windows** 需要 JDK 17：运行 `./windows/build.ps1 -Package`，然后打开 `dist/latest/Mininotes-Windows-<version>/` 中的 `Mininotes.exe`。参见 [windows/README.md](windows/README.md)。

**检查**：Android 上约 870 个单元测试，Windows 上约 1,360 个，无需设备。它们覆盖那些一旦出错就会让人丢失所写内容的地方：合并、收到的笔记、谁可以做什么、数据库结构迁移、配对、附件。需要真实设备才能检查的部分，会在每次发布前在两部手机和一台电脑上检查，并记录在维护者私下保存的日志中，因为日志里有他们设备的名称，还引用了他们的笔记。如需某个构建的记录，请在议题中提出。
