# Mininotes

Mininotes は、スマホと PC で使えるノートです。メモ、フォルダー、ファイルをすべてのデバイスで同じに保ち、あなたが選んだ人と共有します。サーバーもアカウントもなく、間に入る人もいません。すべては Minima ネットワーク上をエンドツーエンドで封をされたまま届くか、同じ Wi-Fi 上でデバイスからデバイスへ直接届きます。

[![最新リリース](https://img.shields.io/github/v/release/mininotesorg/mininotes?label=latest%20build)](https://github.com/mininotesorg/mininotes/releases/latest)

## 1. 新しくなったこと

新しいものから順に並べています。特に断りがない限り、どのバージョンもスマホと PC で同じです。

### 0.4.028

- タイムスタンプ済みのメモやファイルを共有すると、タイムスタンプも一緒に届きます。共有相手は *Minima でタイムスタンプを押す…* でそれを見られます。受け取ったものとまったく同じ場合に限り、受け取ったもののタイムスタンプとして表示され、Minima Explorer で確かめるリンクも付きます。共有したあとに押したタイムスタンプも相手に届きます。
- Integritas レポートを隣に保存しているファイルを共有するとき、*Integritas レポートも送る* でレポートも送れます。
- 最初の起動時の言語のウィンドウは英語で表示され、言語はアルファベット順に並びます。

### 0.4.024 から 0.4.027

- **Minima でタイムスタンプを押す…** は、メモやファイルのメニューの 1 行になり、タイムスタンプがどこまで進んでいるかを示します。開くひとつのウィンドウに、すべてがまとまっています。タイムスタンプを押す、Minima で探す、もう一度確認する、以前にタイムスタンプを押したバージョン、ファイルをフィンガープリントと照合する、です。Integritas の PDF レポートは、メモに添付することも、ファイルの隣に保存することもできます。
- タイムスタンプはほかのデバイスにも届きます。スマホでタイムスタンプを押したものは PC の一覧に表示され、その逆も同じです。
- タイムスタンプ済みのファイルは、アイコンに小さなスタンプが付きます。
- *フィンガープリントと照合…*：あるファイルについて受け取った SHA-256 を貼り付けると、同じファイルかどうかがすぐにわかります。デバイスの外には何も出ず、アカウントも不要です。
- Integritas の返答はあなたの言語で表示され、すぐに返事がないときは、もう一度問い合わせます。
- PC では、すべての画面、ボタン、ポインターの下に出る説明の言葉があなたの言語になりました。新しいノートの最初のフォルダーも、その言語で名付けられます。フランス語では、新しいメモに *nouv.* と付きます。
- まだリレーにつながろうとしている間に画面が描き直されても、スマホが応答しなくなることはなくなりました。

### 0.4.021 から 0.4.023

- メモのタブは、PC ではドラッグで、スマホでは長押しして運ぶことで並べ替えられます。タブのメニューには *左へ移動* と *右へ移動* もあります。
- 言語は、どれかが確定するまで起動のたびに尋ねられます。スマホでは言語をタップするだけで決まります。
- それぞれのアプリがもう一方を紹介します。PC には *スマートフォンの Mininotes…*、スマホには *PC の Mininotes…* があり、スキャン用のコードが表示されます。
- Windows のインストーラーは Mininotes のロゴを表示し、終了時に Mininotes を起動できます。
- Temp で書き始めたメモは、最初の文字を書く前に画面が描き直されても Temp に残ります。
- デバイスどうしが、あるファイルを持っていることを何度も伝え合わなくなりました。これでデバイスが忙しくなっていました。

### 0.4.019 から 0.4.020

- 新しくインストールすると、まず言語を尋ね、README と最初のメモがその言語で書かれます。README は 11 の言語で読めます。
- PC では、ホーム、フォルダー、Temp で Ctrl+V を押すと、クリップボードの画像やファイルがそこに置かれます。
- PC 用のインストーラー（MSI）ができました。管理者権限は不要で、Mininotes は「設定」の「アプリ」に表示されます。メニューには *Mininotes をアンインストール…* があり、バックアップを勧めたうえで、メモを残すかどうかを選べます。バックアップなしで 30 日たつと、Mininotes がお知らせします。
- PC で、太字、斜体、リンクのある行が重なって描かれなくなりました。
- スマホでは、Mininotes が閉じている間に届いたものが、ひとつの通知にまとめられます。
- *Minima でタイムスタンプ済み…* は、タイムスタンプを押したものをすべて一覧にし、+ でさらにタイムスタンプを押せます。

### 0.4.016 から 0.4.018

- スマホは再起動やアップデートのあと、自動でまた受信を待ちます。

## 2. インストール

**Android**（9 以降）：[最新リリース](https://github.com/mininotesorg/mininotes/releases/latest)から `Mininotes-<version>.apk` をダウンロードし、公開されたファイルと同じであることを確かめてから、スマホで開きます。

```sh
sha256sum -c Mininotes-<version>.apk.sha256
```

Android は、ダウンロード元からのインストールを許可するかどうかを尋ねます。この許可は、あとでまたオフにできます。

**署名した人を確かめる**。リリースの APK は、どれも同じ Mininotes の鍵で署名されています。その SHA-256 証明書フィンガープリントは、[AppVerifier](https://github.com/soupslurpr/AppVerifier) で使える形では次のとおりです（2 行をコピーしてから *Verify from clipboard*）。

```
org.mininotes.android
F7:91:C2:14:D9:ED:9B:E9:DE:EC:6F:15:BE:D0:25:38:35:22:DD:F9:A8:21:23:4A:73:90:C8:1B:60:1F:91:AB
```

Android SDK を使う場合は `apksigner verify --print-certs Mininotes-<version>.apk`。これ以外のフィンガープリントは、このリポジトリのリリースからのビルドではありません。

**Windows**（10 または 11）：同じリリースから `Mininotes-Windows-<version>.msi` をダウンロードして開きます。管理者権限は不要で、インストール後の Mininotes はほかのアプリと同じように Windows の「設定」の「アプリ」に表示されます。そこでアンインストールしてもメモは残り、あとで再インストールすると再び見つかります。アプリのメニューの *Mininotes をアンインストール…* なら、バックアップを勧めたうえでメモも削除できます。Java は中に含まれているので、ほかに何もインストールする必要はありません。

または、お好みで `Mininotes-Windows-<version>.zip` も使えます。好きな場所に展開して `Mininotes.exe` を開きます。

どちらも、ほかには何もいりません。メモを運ぶ Maxima ノードはアプリの中にあります。

## 3. 書く

- **罫線のページが、すぐ使えます**。メモはカーソルが入った状態で開き、書くそばから保存されます。保存ボタンはありません。
- **タブ**。1 つのメモに、インデックスカードのように複数のページを持てます：*タブを追加*。タブはドラッグで並べ替えられます。
- **太字、斜体、下線**。語の前後に記号を入力するか（`**bold**`、`*italic*`、`__underline__`）、キーボードで Ctrl+B、Ctrl+I、Ctrl+U を押します。
- **1 つのメモに 2 人で**。2 人が互いの内容を見る前に同じメモに書いても、2 つは行ごとにまとめられ、どちらが書いたものも失われません。それぞれが書いた部分を自分の色で表示できます。タイトルの下の丸いアイコンをタップすると、色を変えられます。
- **ほかのアプリから**。Android では、Mininotes が共有シートに表示されます。スクリーンショット、写真、ファイル、テキスト、リンクを、新しいメモや最近使ったメモに入れられます。

## 4. ホーム、フォルダー、ドック、お気に入りで整理する

- **ホーム**には、メモとフォルダーがアイコンとして並びます。ページはいくつでも作れ、どれも置いた場所にとどまります。
- **何かを作る**。+ をタップすると、メモやフォルダーを作ったり、このデバイスや別のデバイスからファイルを追加したりできます。
- **メニュー**。アイコンを長押しするとメニューが開きます：色、アイコン、移動、共有などです。PC では右クリックします。PC ではロゴでホームに戻り、仕切りをドラッグしてサイドの一覧の幅を変えたり、折りたたんだりできます。
- **フォルダー**には、メモやほかのフォルダーを何階層でも入れられます。何でもフォルダーの上にドラッグすれば、その中に入ります。
- **動かす**。アイコンを長押ししてドラッグします：フォルダーの中へ、外へ、または別のページへ。ドラッグ中は、上部の帯を使って、メニューなしでお気に入り、Temp、アーカイブ、ゴミ箱、共有の上に直接落とせます。
- **ページ**。スワイプでページを切り替えます。ホームをピンチするか、メニューで*すべてのページ*を選ぶと、全ページを一度に見られます。
- **色とアイコン**。メモやフォルダーごとに、メニューから色と、アイコンまたは画像を設定できます。色の濃さもそれぞれ別で、色の下のスライダーで設定します。ホームの色がアプリ全体の色になります。
- **ドック**はホームのいちばん下の列です。そこに置いたものは、ワンタップで開けます。*ドックに追加*は、お気に入りを除くすべてのメモとフォルダーのメニューにあります。いくつでも置けて、収まらないときは横にスクロールします。ドックはデバイスごとに別々で、ほかのデバイスに送られることはありません。
- **お気に入り**には、よく戻ってくるものを 1 か所にまとめます。新しくお気に入りにしたものはドックにも入り、お気に入りから外してもドックには残ります。
- **最近**には、最近開いたものが並びます：PC ではサイドに、スマホではホームに。*最近から削除*（PC では右クリック）で一覧から外せます。何も削除されません。スマホでは、ドックから上にスワイプするか、そのすぐ上のハンドルをタップすると、最近のものをカードでめくれます：カードをタップすると開き、スワイプで払うか「戻る」を押すと閉じます。
- **Temp** は、しばらくの間だけ必要なものを置く場所で、自分のデバイスや選んだ人との受け渡しにも使います。中身は相手に届き、期限が来るとすべての場所から消えます。
- **共有されたもの**には、ほかの人があなたと共有し、返事を待っているものが入ります（[ほかの人と共有する](#6-ほかの人と共有する)を参照）。
- ホームの下にある**検索**で、メモ、フォルダー、ファイルを言葉で探せます。**ツリー**はすべてを一度に表示します。
- **アーカイブとゴミ箱**：片付けておく場所と、捨てる途中の場所です。どちらからも元に戻せます（[バージョン、アーカイブ、ゴミ箱、バックアップ](#11-バージョンアーカイブゴミ箱バックアップ)を参照）。
- ホームの **README** はこの文章で、GitHub のものと同じですが、GitHub でだけ意味のある部分（目次、新しくなったこと、インストール、ビルド、すべてのメニュー項目の一覧。PC ではその説明がポインターの下に出ます）は省いています。
- *設定*の**ホームに表示**では、ホームに表示する場所（最近、Temp、共有されたもの、アーカイブ、ゴミ箱）と、README を表示するかどうかを選びます。オフにしたものも、メニューには残ります。
- **写真**：最初からホームにあるアルバムフォルダーで、中の画像がすべてグリッドで並び、1 枚ずつ大きく開けます。次や前の写真へは、スワイプか矢印ですぐ移れます。+ で写真を追加するか、撮影します。どのフォルダーも、メニューからアルバムとして表示できます。

## 5. 自分のデバイス

スマホと PC を一度つなげます（*人とデバイス*、次に*自分のデバイスを追加*を選び、片方のコードをもう片方でスキャンします）。それ以降は、自分のデバイスと共有したものが、書くのをやめて数秒後に、すべてのデバイスで双方向に自動で最新になります。見るだけでよいデバイスは*閲覧可*にできます。レイアウトはデバイスごとに別々です：一方でメモを置いた場所は、もう一方では動きません。ドックもそれぞれ別です。

## 6. ほかの人と共有する

- **誰かを追加**：相手のコードをスキャンするか、送られてきたリンクを開きます。相手も、あなたのコードやリンクで同じようにします。
- **メモ、フォルダー、ファイルを共有**：そのメニューから*同期と共有*、次に*共有…* を選びます。まず相手にできることを選び、次に人かグループを選ぶか、自分のコードを見せます。一人ひとりに役割があります：*オーナー*（作った人）、*管理者*、*書き込み可*、*閲覧可*。役割はいつでも横のドロップダウンで変えたり、外したりできます。
- どの + にもある**別のデバイスから…** で、誰かが見せてくれたものを受け取ります。
- **グループ**（友だち、同僚など）で人をまとめます。グループと共有すると、あとから加わった人も含め、全員が同じ役割になります。
- **承認か拒否か**。誰かがあなたと共有すると、お知らせが届き、*共有されたもの*で待っています。それが何で誰が送ったかを見て、ほかのどこかに入る前に、置き場所を選べます。残すなら*承認*、断るなら*拒否*。黙って断ることも、ひとこと返すこともできます。
- **色も一緒に届く**。共有メモに付けた色はメモと一緒に届き、濃さはデバイスごとに設定できます。
- **共有フォルダーの中身はすべて共有される**。共有したフォルダーに入れたものは、そのフォルダーを共有した人に届きます。
- メモのタイトルの横の**丸いアイコン**は、そのメモを持っている人とデバイスで、それぞれ写真か頭文字が表示されます。タップすると、写真が大きく表示されます。PC では、丸いアイコンにポインターを置くと、それが誰か、そのメモで何ができるか、書いた内容の同期がどこまで進んでいるか、ファイルがあといくつ届く途中かが表示されます。

## 7. 人とデバイス、そしてマイプロフィール

どちらもメニューの*同期と共有*の最後にあります。

- **人とデバイス**には、追加した人、自分のデバイス、グループが、それぞれ専用のページで並びます。人のページには、その人と共有しているものが表示され、好きな画像をその人に付けられます（あなたにしか見えません）。グループの設定はその › の先にあります。
- **人の横の +** で誰かとつながります：相手のコードをスキャンするか、リンクを貼り付けるか、*自分のリンクを共有*でメッセージやチャットで自分のリンクを送ります。**自分のデバイスの横の +** で、自分の別のデバイスを追加します。
- **マイプロフィール**には、あなたのものが入っています：
  - あなたの**名前**と**画像**。ペアリングした相手に届きます。
  - あなたの **Parlons! アドレス**。連絡先に自動で送られます。
  - あなたのコードとリンク。ほかの人があなたを追加するためのものです。
  - **Integritas** の API キー（[Integritas で Minima にタイムスタンプを押す](#13-integritas-で-minima-にタイムスタンプを押す)を参照）。
  - PC では**文字サイズ**：A− と A+ による 5 段階で、「小」から「最大」まであり、アプリ全体（ホーム、最近、メニュー、ボックス）に効きます。次回の起動から反映され、*今すぐ再起動*もあります。
  - PC では**それぞれの働きを説明**：最初からオンで、メニュー項目や丸いアイコンにポインターを置いたときに出る短い説明をオン・オフします。
  - *管理…*：人とデバイスを開きます。

## 8. すべての状況を把握する

- すべてのメモ、フォルダー、アイコンに付く**マーク**が状況を示します：灰色の空の輪は、このデバイスにだけあるもの。琥珀色の矢印は送信待ち（押すと今すぐ送り、まだ待っているメモとファイルを 1 つずつ確認できます）。琥珀色の 3 つの点は、送信済みで返事待ち。緑のチェックは、全員がこのバージョンを持っていること。灰色の 2 本の棒は一時停止中。赤い感嘆符は、3 日以上届いていないデバイスがあることを示します。
- **新規**には、前回見てから変わったものが並びます：ほかの人が書いたメモ、あなたと共有されたもの、届いたファイル。それぞれ誰が送ったか、いつか、どこにあるかも分かります。
- **上部の帯**は、連絡先に何か問題があるときに表示されます（何日も届いていないデバイス、ロックされたデバイス、古い Mininotes を使っているデバイス）。Mininotes は自動で試し続け、*どうすればいいか*で、あなたにできることが分かります。

## 9. ファイル、写真、録音

- **添付**：どんなファイルでも、メモやフォルダーに一度に複数添付できます。
- **写真を撮る**：メモから撮影します。スマホのカメラ、PC では Windows 標準のカメラを使い、写真はそのままメモに入ります。
- **録音**：メモに音声を録音します。
- **軽く運ぶ**。写真は追加するときに小さくするので、写真 50 枚のメモでも軽く届きます。これは*設定*、*画像とファイル*でオフにできます。ほかのファイルは、容量を節約するために圧縮されます。
- **プレビュー**。PDF のカードには最初のページが、Word、PowerPoint、Excel、OpenDocument、RTF、HTML、テキストファイルのカードには最初の数行が表示されます。プレビューは Mininotes がファイルそのものから描いたもので、Windows やほかのアプリに描かせることはないので、外部にその画像が残ることはありません。
- **開く**：ファイルを、コンピューターがその種類に使うプログラムで開くか（たとえば *LibreOffice で開く*）、*プログラムから開く…* で別のプログラムを選びます。保存した変更は Mininotes に戻り、自分のデバイスに届きます。
- ファイルで**コピー**（PC では右クリック、スマホでは長押し）を使うと、ファイルそのものがクリップボードに入り、画像は画像として入ります。先に保存しなくても、ほかのアプリに貼り付けられます。
- **外に保存する**。*このコンピューターに保存…*（スマホでは*このスマホに保存…*）で、選んだ場所にコピーを保存します。*自分のデバイスに保存…* では、このデバイスのフォルダーにもファイルとして保管します。
- スマホの**別のアプリで送る…** は、スマホ標準の共有を開きます。たとえば WhatsApp でファイルを送れます。長押ししたファイルで*複数を選ぶ…* を使うと、複数にチェックを付けて、まとめてこの方法で送ったり、ゴミ箱に入れたりできます。
- **PC で複数をまとめて**。クリップのメニューには*ファイルを添付*、*写真を撮る*、*録音*があり、その下にメモのファイルがチェックボックス付きで並びます：*すべて選択*してから、チェックしたものに*このコンピューターに保存…*（複数なら 1 つのフォルダーに入ります）、*Minima でタイムスタンプを押す…*、または*ゴミ箱へ移動*を使います。
- **ファイルを送る**：メモに入れずに、自分の別のデバイスや追加した人へ直接送ります。同じ Wi-Fi なら、端末から端末へ直接届きます。届いたものはホームに置かれ、開くまで*新規*のマークが付きます。
- **Minima でタイムスタンプを押す…**（ファイルやメモのメニューにあります）：[Integritas で Minima にタイムスタンプを押す](#13-integritas-で-minima-にタイムスタンプを押す)を参照。

## 10. PC に置いたままのファイル

- **Mininotes でファイルを共有**（PC の*同期と共有*にあります）：表計算や文書は PC の元の場所にとどまり、専用のプログラムで開きます。保存するたびに、そのバージョンがほかのデバイスに届き、ほかで保存されたバージョンはこのファイルに書き戻されます。届くのはファイル全体の最新版です：表計算の中の変更はまとめられません。2 か所で変更されてから両方が出会った場合は、Mininotes がどちらのバージョンを残すか尋ね、答えるまで何も置き換えません。
- **この PC のフォルダーを同期**（PC の*同期と共有*にあります）：C: でもどこでもフォルダーを選ぶと、中身がすべて Mininotes に、PC 上にあることを示すマーク付きのフォルダーとして表示されます。エクスプローラーやどのプログラムからでも、そこに入れたファイルは数秒後に取り込まれ、自分のデバイスと、そのフォルダーを共有した相手に届きます。相手から届いたファイルは、そのフォルダーに書き込まれます。ファイルは PC 上のそのフォルダー、つまりアプリの外にとどまります。ディスク上で削除しても Mininotes で削除されることはなく、その逆もありません。ファイルが両方で変更された場合は、Mininotes がどちらのバージョンを残すか尋ねます。スマホでは、フォルダーのファイルはアプリの中に保管されます。
- **メモをファイルとして**。メモやフォルダーは、PC 上の好きなフォルダーに Markdown ファイルとしても保管できます（*自分のデバイスに保存…*）。Mininotes がこれらのファイルを削除することはなく、プライベートメモが書き出されることもありません。
- このようなフォルダーのタイルには、矢印付きのフォルダーが表示されます。メニューには PC 上の場所が表示され、続いて*エクスプローラーで表示*、*アプリ内だけに保存*、*アプリから削除*があります。

## 11. バージョン、アーカイブ、ゴミ箱、バックアップ

- **バージョン**。メモのバージョンはすべて残ります。*バージョン…* で、どれでも元に戻せます。
- **アーカイブ**は、見えない所にものをしまいます。**ゴミ箱**は、空にするまで、削除したもの（ファイルも含む）を保管します。どちらもホームにあり、そこから戻る道もあります。*元に戻す*で、ものを元の場所に戻します。
- **ゴミ箱のメモのファイル**。メモから外したファイルは、確認なしですぐにゴミ箱に入り、すべてのデバイスで、そしてそのメモが届くすべての人のところで、メモから取り除かれます。*元に戻す*で、すべての場所に戻ります。完全に消えるのは、ゴミ箱を空にしたときだけです。
- **バックアップ**。*バックアップを書き出す*で、すべてのフォルダー、メモ、ファイルを含む 1 つのファイルを書き出します。ロックを使っていない場合（[プライバシー、暗号化、安全のために](#14-プライバシー暗号化安全のために)を参照）は、そのバックアップ用のパスワードを尋ねます。*バックアップから追加*でバックアップを戻し、今あるものに追加するか、置き換えるかを尋ねます。

## 12. エージェントに頼んで、やってもらう

**エージェント**（PC では上部のバー、スマホではメニューの横、または Ctrl+K）は、アプリに入っているヘルプ（[英語のヘルプ](android/app/src/main/resources/org/mininotes/android/help/en.txt)、[フランス語のヘルプ](android/app/src/main/resources/org/mininotes/android/help/fr.txt)）をもとに Mininotes についての質問に答え、英語かフランス語で頼んだ簡単な作業をこなします：*what is new?*、*what is on my todo list?*、*add milk to Grocery*、*share Grocery with Carol*、*add a contact*、*open*、*find*、*new note called…*、*put … in the dock*。モデルもサーバーも使わずにあなたのデバイス上で動き、何も送信しません。ほかの人に届くことやメモを変えることは、実行する前に見せてくれます。適切な場所へ案内もしてくれます。ボックスの外を押すと閉じます。

## 13. Integritas で Minima にタイムスタンプを押す

[Integritas](https://docs.integritas.technology/) のアカウントがあれば、ファイルやメモに、そのメニューから Minima ブロックチェーン上のタイムスタンプを押せます。デバイスから出るのはフィンガープリント（SHA-256）だけで、ファイルそのものは決して出ません。

- **Minima でタイムスタンプを押す…** は、ファイルが今まさにその状態で存在することを記録します：その時点から存在し、それ以降変わっていないことの証明です。Integritas アカウントのタイムスタンプを 1 つ使います。
- **Minima で確認…** は、あとでファイルを記録と照らし合わせます：タイムスタンプが押されているか、変わっていないか、どのブロックにいつ記録されたか。何も変えず、費用もかかりません。
- **違い**：タイムスタンプを押すのは証明を一度書くこと、確認はそれを読み返すことで、何度でもできます。
- **メモのタイムスタンプ**は、タイトル、空行 1 行、本文の順に対象とします。名前を変えると、変更されたことになります。0.4.018 より前に押したタイムスタンプは、本文だけが対象です：*メモ、本文のみ*。
- **マイプロフィール、タイムスタンプ**：API キーを貼り付けて*保存*を押します。キーはノートの中に、ノートと一緒にロックされて保管され、バックアップには決して入りません。*自分のほかのデバイスにも*で自分のデバイスをオンにすると、キーはそれぞれのデバイス用に封をされて届きます。
- **Minima でタイムスタンプ済み…** は*検索*の最後にあり、ここでタイムスタンプを押したものの一覧です。開くと、フィンガープリント、ブロック、トランザクションが分かります。その **+** で、Mininotes の中のメモやファイル、または Mininotes に入れていないこのデバイス上のファイルに、タイムスタンプを押せます。

## 14. プライバシー、暗号化、安全のために

- **サーバーなし、アカウントなし、追跡なし**。メモはあなたのデバイスに保管され、共有した人とデバイスにだけ届きます。
- **エンドツーエンドで封をする**。メモやファイルは、届け先のデバイス用に一つひとつ封をされ、[Maxima](https://minima.global) のリレーが運びます。リレーは、読めないメッセージを中継するだけです。同じネットワーク上なら、デバイスからデバイスへ直接届きます。
- **Mininotes をロック**（*設定*、*セキュリティ*）すると、デバイス上のノート、そのファイル、バックアップが暗号化されます。スマホでは指紋か画面ロック、PC では Windows Hello かパスワードで開き、予備の鍵として 12 個の復元用の単語があります：書き留めておいてください。ロックしないと、メモはデバイス上で暗号化されません。
- **ネットワークを使うのは 2 つだけ**：共有したものを運ぶ Maxima ノードと、1 日 1 回このリポジトリで新しいバージョンがあるか確かめること（オフにできます）です。[docs/SHARING.md](docs/SHARING.md) に、何が封をされ、何が署名され、何がまだ作られていないかが書いてあります。

## 15. プライベートスペースとヘルプのリクエスト

**プライベートスペース**

- **開く、または作る**。どのメモでもいいので、private という単語を入力し、続けて //: とパスワードを、間に何も入れずにつなげて入力し、Enter を押します。コロンを入力した瞬間にコードはメモから消え、パスワードは専用のボックスに入るので、どちらもメモには残りません。そのパスワードで開くスペースは、ウィンドウ全体を覆う専用の画面に表示されます。一度も使ったことのないパスワードなら、もう一度入力すると、新しい空のスペースが作られます。
- **パスワードごとに 1 つのスペース**。パスワードが違えば、それぞれ別のスペースです。作れる数に上限はなく、いくつ持っているかはどこにも記録されません。
- **パスワードはすべて書き留める**。どこにも記録されないので、打ち間違えたパスワードは新しいスペースとして再入力を求められます。既存のスペースを開くつもりでこうなったら、ボックスを閉じてやり直してください。新しいスペースが以前のスペースの上に重なり、その一部が失われることがあります。
- **今いる場所**。プライベートの画面には専用の色があり、*プライベート*の横に錠前があるので、今どこにいるか常に分かります。下の + でメモ、フォルダー、ファイルを作ります。パスワードの横の目のアイコンを押している間、パスワードが表示されます。「戻る」でスペースを閉じます。
- **削除する**。スペースを開いて、メニューの*このプライベートスペースを削除*を選びます。スペースは完全に消え、そのパスワードではその後何も開けません。
- **長いパスワード**。いくつかの単語からなる長いフレーズをパスワードにしてください。忘れたパスワードは誰にも復元できず、12 個の復元用の単語でも戻せません。
- **入るもの**。1 つのスペースには全部で約 64 MB、メモと写真 50 枚ほどが入ります。中のメモ、フォルダー、写真、ファイルはほかのどこにも表示されず、今のところこのデバイスにだけ保管され、共有や送信はできません。Mininotes を離れるか、5 分間使わないと閉じます。
- **コードが普通のメモに残ることはない**。メモにコードが残っていたら、Mininotes はメモを保存、送信、共有する前に、その行の残りと一緒に取り除きます。
- **ファイル**。+ の*このデバイスから…* でファイルをスペースに追加すると、暗号化して保管されます。削除を選ばない限り元のファイルはそのまま残り、スマホのファイル選択画面は、最近開いたファイルの一覧を独自に持っています。
- **ヒント**。1 つのパスワードでそれらしいスペースを、別のパスワードで本当のスペースを持ち、それらしいほうもときどき使って、使っている感じを出しておけます。
- **限界**。プライベートスペースは、アプリのファイルやコードを読んでも誰にも見えず、いくつあるかも分からないように作られています。ただし 100% 安全だと確認することはできないので、見つかっても困らないものだけを置いてください。

**緊急連絡先**

- **これは何か**。ヘルプのリクエストは、プライベートメモが開かれた瞬間に、あなたの位置情報と、あなたが選んだ言葉を、あなたが選んだ人に送ります。危険な状況にあって、誰かに Mininotes を開かされるかもしれないときのためのものです。
- **設定する**。プライベートスペースを開き、その中のメモを 1 つ開いて、help という単語を入力し、続けて //: をつなげて入力し、Enter を押します。コードはすぐに消え、誰に知らせて何を伝えるかを尋ねるボックスが開きます。入力したメモが、リクエストを送るメモになります。設定したり外したりできるのは、そのスペースのパスワードを知っている人だけです。
- **二度と表示されない**。一度設定すると、どこにも二度と表示されません：どのメニューにも出ず、ボックスはいつも空の状態で開きます。
- **すべて外す**。スペースのヘルプのリクエストをすべて外すには、その中のメモで erase という単語を入力し、続けて //: を入力します。このコードもすぐに消えます。
- **位置情報**。そのために Mininotes はスマホの位置情報の許可を求めます。位置情報が使われるときは、システムが表示します。

## 16. 言語と翻訳

Mininotes は 11 の言語で使えます：英語、フランス語、ドイツ語、スペイン語、イタリア語、ポルトガル語、ロシア語、中国語、日本語、ヒンディー語、ペルシア語。最初の起動時にどの言語にするか尋ね、デバイスの言語があらかじめ選ばれています。この README もその言語で表示されます。*設定、言語*で両方を変えられます。メモのメニューの*翻訳…* は、翻訳サービスに送らずに、デバイス上でページを別の言語にします。

## 20. 自分でビルドする

**Android** には JDK 17 と Android SDK（compileSdk 36）が必要です。

```sh
cd android
./gradlew testReleaseUnitTest lintRelease assembleRelease
```

APK は `android/app/build/outputs/apk/release/` に、署名なしでできあがります。自分の鍵で署名するか、`./gradlew installDebug` を使ってください。`android/local.properties` は SDK の場所を指すもので、リポジトリには含まれていません。

**Windows** には JDK 17 が必要です：`./windows/build.ps1 -Package` を実行し、`dist/latest/Mininotes-Windows-<version>/` の `Mininotes.exe` を開きます。[windows/README.md](windows/README.md) を参照してください。

**テスト**：Android で約 870、Windows で 1,360 の単体テストがあり、デバイスは不要です。間違えると誰かの書いたものが失われる部分を対象にしています：マージ、届いたメモ、誰が何をできるか、スキーマの移行、ペアリング、添付ファイル。実機が必要な部分は、リリースのたびに 2 台のスマホと 1 台の PC で確認し、メンテナーが非公開で保管している記録に残しています。その記録にはデバイス名やメモの引用が含まれるためです。あるビルドの記録が見たいときは、issue で尋ねてください。
